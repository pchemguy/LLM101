# Введение

Актуальность темы исследования. В современных условиях цифровизации промышленности вопросы повышения эффективности решений остаются значимыми.

Степень разработанности проблемы. Несмотря на наличие исследований, остается недостаточно разработан механизм оценки влияния цифровых решений.

Цель исследования состоит в разработке подхода к оценке влияния цифровых решений.

Задачи исследования:
1. Уточнить основания оценки.
2. Разработать систему показателей.
3. Сформулировать рекомендации.

Объект исследования — процессы принятия решений.
Предмет исследования — отношения в процессе применения цифровых решений.

Методология и методы — системный подход, сравнительный анализ.

Научная новизна состоит в разработке системы показателей.
Теоретическая значимость состоит в развитии подходов к оценке.
Практическая значимость состоит в возможности применения результатов.

Апробация результатов осуществлялась на конференциях.
