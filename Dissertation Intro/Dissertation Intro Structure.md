# Composition of a Russian Dissertation Introduction

Dissertation introduction is a **structured justification of the research project** moving through a sequence:

1. **Problem relevance**
2. **State of research**
3. **Research problem and objectives**
4. **Research design**
5. **Research contribution**
6. **Validation and dissemination**

| Component                                                                          | Functional Role in Research Logic          | What This Section Must Establish                                                                                                                                               |
| ---------------------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Актуальность темы исследования**                                                 | Problem relevance / motivation             | Demonstrates why the research problem matters scientifically, economically, or socially. Identifies the practical or theoretical problem that requires investigation.          |
| **Степень разработанности проблемы**                                               | Literature positioning / research gap      | Reviews existing research and demonstrates what has already been studied, what approaches exist, and what **remains unresolved**. Leads to identification of the research gap. |
| **Цель диссертационной работы**                                                    | Research objective                         | Defines the **overall research goal** — the main scientific result the dissertation intends to achieve.                                                                        |
| **Задачи исследования** *(often listed after the goal)*                            | Operational decomposition of the objective | Breaks the research goal into concrete analytical or methodological steps required to achieve it.                                                                              |
| **Объект исследования**                                                            | Domain of investigation                    | Specifies the **real-world system, process, or phenomenon** being studied (the broader field where the research occurs).                                                       |
| **Предмет исследования**                                                           | Analytical focus                           | Specifies the **particular relationships, mechanisms, or properties** of the object that are analyzed in the dissertation.                                                     |
| **Теоретическая и методологическая основа исследования**                           | Conceptual and methodological framework    | Describes theoretical foundations, schools of thought, and research methods used to analyze the problem.                                                                       |
| **Информационно-эмпирическая база исследования** *(sometimes included separately)* | Data sources                               | Specifies empirical materials, datasets, statistics, reports, or case studies used in the research.                                                                            |
| **Соответствие содержания диссертационного исследования избранной специальности**  | Administrative compliance                  | Demonstrates that the dissertation corresponds to the **official VAK specialty classification** and its research topics.                                                       |
| **Научная новизна**                                                                | Original scientific contribution           | Lists **new theoretical, methodological, or empirical results** obtained by the author that distinguish the work from existing studies.                                        |
| **Теоретическая значимость**                                                       | Contribution to theory                     | Explains how the research advances scientific understanding, concepts, or analytical frameworks.                                                                               |
| **Практическая значимость**                                                        | Applied relevance                          | Demonstrates how the results can be used in practice (policy, management, industry, education).                                                                                |
| **Апробация результатов исследования**                                             | Validation and dissemination               | Shows that results have been presented at conferences, implemented in organizations, or tested in practice.                                                                    |
| **Публикации по теме исследования**                                                | Scholarly output                           | Lists articles and publications derived from the dissertation.                                                                                                                 |
| **Структура диссертации**                                                          | Document structure overview                | Provides a brief description of the chapters and overall structure of the dissertation.                                                                                        |

## Core Research Logic

The entire introduction follows a **simple scientific argument**:

```
Problem exists
     ↓
Existing research is insufficient
     ↓
This dissertation aims to solve the problem
     ↓
Using specific methods
     ↓
Producing new results
     ↓
Which are useful and validated
```

## Ultra-Compact Version (5-Step Model)

If we compress it even further, the introduction can be reduced to **five essential research functions**.

| Step | Function                       | Russian sections        |
| ---- | ------------------------------ | ----------------------- |
| 1    | Why the problem matters        | Актуальность            |
| 2    | What is unknown                | Степень разработанности |
| 3    | What the dissertation will do  | Цель + задачи           |
| 4    | How the research is done       | Объект, предмет, методы |
| 5    | What new knowledge is produced | Научная новизна         |

Everything else is essentially **institutional metadata** required by VAK.

These include:

* соответствие специальности
* апробация
* публикации
* структура работы

## Structural Insight (Important)

The Russian introduction actually mixes **two different types of information**:

### Scientific logic

* актуальность
* степень разработанности
* цель
* задачи
* объект
* предмет
* методы
* новизна

### Institutional reporting

* соответствие специальности
* апробация
* публикации
* структура

This hybrid structure explains why Russian introductions often look **longer and more bureaucratic** than international ones.

# Object–Subject–Goal–Tasks Relationship

The most confusing part of the Russian dissertation introduction is the **logical relationship between four elements**:

* **Объект исследования**
* **Предмет исследования**
* **Цель исследования**
* **Задачи исследования**

In Russian methodology manuals this is often explained as a **nested hierarchy of analytical narrowing**.

## Core Logical Relationship

```
Объект
   ↓
Предмет
   ↓
Цель
   ↓
Задачи
```

Each step **narrows the focus of the research**.

---

## Step-by-Step Interpretation

| Element                  | Function           | Meaning                                                    |
| ------------------------ | ------------------ | ---------------------------------------------------------- |
| **Объект исследования**  | Research domain    | The real-world system or phenomenon                        |
| **Предмет исследования** | Analytical focus   | The specific aspect of the object being studied            |
| **Цель исследования**    | Research objective | What knowledge about the subject the study aims to produce |
| **Задачи исследования**  | Operational tasks  | Steps required to achieve the objective                    |

---

### Object

```

---

### Subject

```

```

Interpretation:

```

Interpretation:

1. Clarify concept of modernization
2. Analyze industry state
3. Develop evaluation methodology
4. Study organizational and economic mechanisms
5. Propose improvement recommendations

Interpretation:

> These are **implementation steps** required to reach the goal.

## Practical Rule Used by Advisors

Many Russian supervisors teach a simple consistency rule:

```
Tasks must collectively achieve the goal.
Goal must address the subject.
Subject must belong to the object.
```

If this chain breaks, the introduction is considered **methodologically incorrect**.

---

## Example of a Fully Consistent Chain

```
Object:
industrial enterprise modernization

Subject:
organizational-economic mechanisms of modernization

Goal:
develop a methodology for improving modernization mechanisms

Tasks:
1. analyze theory
2. study industry practice
3. develop evaluation indicators
4. propose improvements
```

Everything aligns.

## Why This Structure Exists

This structure originates from **Soviet dissertation methodology**, which emphasized:

* **formal logical consistency**
* **clear decomposition of research objectives**
* **explicit methodological framing**

This is why Russian thesis introductions are **much more structured and formulaic** than Western ones.

# Research Pipeline Behind a Russian Dissertation Introduction

The introduction describes the **entire research lifecycle** in compressed form.

```
REAL-WORLD PROBLEM
        ↓
SCIENTIFIC CONTEXT
        ↓
KNOWLEDGE GAP
        ↓
RESEARCH DESIGN
        ↓
RESEARCH RESULTS
        ↓
VALIDATION AND IMPACT
```

The canonical Russian sections correspond almost one-to-one to these stages.

If we remove institutional requirements, the whole introduction reduces to **six scientific components**.

| 3    | What remains unknown           |

## Ultra-Condensed Logical Formula

The Russian dissertation introduction can be expressed as one sentence:

```
Because an important problem exists
and current research does not fully solve it,
this dissertation aims to achieve a specific objective,
using defined methods and data,
in order to obtain new scientific results
that have theoretical and practical significance.
```

# 4-Sentence Model of a Dissertation Introduction

## Sentence 1 — Problem significance

**Because** an important scientific or practical problem exists.

Corresponds to:

* **Актуальность темы исследования**

Example:

> В условиях усиливающейся глобальной конкуренции возрастает необходимость повышения эффективности модернизации предприятий нефтеперерабатывающей промышленности.

---

## Sentence 2 — Knowledge gap

**Although** the problem has been studied, important aspects remain insufficiently developed.

Corresponds to:

* **Степень разработанности проблемы**

Example:

> Несмотря на значительное число исследований, посвящённых модернизации промышленных предприятий, недостаточно разработаны организационно-экономические механизмы модернизации нефтеперерабатывающих предприятий.

---

## Sentence 3 — Research objective

**Therefore**, the dissertation aims to solve this problem.

Corresponds to:

* **Цель исследования**
* **Задачи исследования**

Example:

> Целью диссертационного исследования является разработка методических подходов и практических рекомендаций по совершенствованию организационно-экономического механизма модернизации предприятий нефтеперерабатывающей промышленности.

---

## Sentence 4 — Contribution

**As a result**, the research produces new scientific results.

Corresponds to:

* **Научная новизна**
* **Теоретическая и практическая значимость**

Example:

> Научная новизна исследования заключается в разработке комплекса методических положений и практических рекомендаций по совершенствованию организационно-экономического механизма модернизации предприятий нефтеперерабатывающей промышленности.

---

## The Logical Formula

In abstract form the entire introduction is simply:

```
Problem exists
+
Existing research is insufficient
→
Research objective
→
New scientific contribution
```

Or in natural language:

```
Because a problem exists,
and existing research does not fully solve it,
this dissertation aims to achieve X,
resulting in new scientific knowledge Y.
```

## Why This Model Is Useful

It helps verify **logical consistency**.

A good introduction should satisfy:

```
Problem → Gap → Objective → Contribution
```

If any of these links are missing:

* the dissertation may appear **methodologically weak**
* the introduction becomes **descriptive instead of argumentative**

---

## A Useful Teaching Heuristic

When reviewing a dissertation introduction, ask four questions:

1. **Why is this problem important?**
2. **What exactly is still unknown?**
3. **What does this dissertation aim to achieve?**
4. **What new knowledge does it produce?**

If the answers are clear, the introduction is usually well structured.

## Key Logical Consistency Rules

The introduction should satisfy the following chain.

```
Problem importance
       ↓
Research gap
       ↓
Research objective
       ↓
Research tasks
       ↓
Research design
       ↓
Scientific contribution
```

If the logic breaks at any point, reviewers often criticize the dissertation.

---

## Critical Consistency Checks

### 1. Goal–Task Consistency

```
Tasks must collectively achieve the goal.
```

If a task does not contribute to the goal, it is methodologically incorrect.

---

### 2. Object–Subject Consistency

```
Subject ⊂ Object
```

The subject must be **a specific aspect of the object**.

Example:

```
Object:
modernization of industrial enterprises

Subject:
organizational-economic mechanisms of modernization
```

---

### 3. Novelty–Goal Consistency

```
Novelty must correspond to the goal.
```

If the goal is methodological, the novelty must also be methodological.

---

### 4. Methods–Tasks Consistency

```
Methods must allow solving the stated tasks.
```

Example:

| Task                            | Required method      |
| ------------------------------- | -------------------- |
| Analyze industry trends         | statistical analysis |
| Develop evaluation model        | economic modeling    |
| Assess modernization efficiency | indicator system     |

---

## Minimal Logical Skeleton

The entire introduction can be reduced to the following structure:

```
1 Problem importance
2 Existing research
3 Research gap
4 Research goal
5 Research tasks
6 Research scope (object/subject)
7 Research methods and data
8 Scientific contribution

```

Everything else is elaboration.

# Introduction as a Research Design Specification

A useful way to rationalize the Russian dissertation introduction is to view it not as a list of formal elements but as a **compact specification of the research design**.

In this interpretation, the introduction performs four essential scientific functions:

1. **Justify the problem**
2. **Position the research within existing knowledge**
3. **Define the research design**
4. **Present the contribution and validation**

This produces a **problem → research program → contribution** structure.

| Russian Component                        | Research Design Role     | What It Formally Defines                                                                                        |
| ---------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| **Актуальность темы исследования**       | Problem justification    | Establishes the real-world or theoretical problem motivating the study. Demonstrates significance and urgency.  |
| **Степень разработанности проблемы**     | Literature positioning   | Defines the current state of knowledge and identifies unresolved issues, thereby locating the **research gap**. |
| **Цель исследования**                    | Target scientific result | Specifies the main intellectual result the dissertation intends to obtain.                                      |
| **Задачи исследования**                  | Research program         | Defines the analytical steps required to achieve the goal. Often corresponds to dissertation chapters.          |
| **Объект исследования**                  | Domain boundary          | Specifies the system, process, or phenomenon being studied.                                                     |
| **Предмет исследования**                 | Analytical scope         | Specifies the particular relationships or mechanisms within the object that are examined.                       |
| **Теоретическая база исследования**      | Conceptual framework     | Identifies theories and conceptual models used to interpret the phenomenon.                                     |
| **Методологическая основа исследования** | Research methods         | Specifies analytical methods, empirical techniques, and modeling approaches used to obtain results.             |
| **Информационно-эмпирическая база**      | Evidence base            | Defines datasets, statistics, case studies, or documents used for analysis.                                     |
| **Научная новизна**                      | Original contribution    | Lists specific new scientific results obtained by the author.                                                   |
| **Теоретическая значимость**             | Theoretical advancement  | Explains how the research extends existing theory.                                                              |
| **Практическая значимость**              | Practical impact         | Shows how results can be applied in policy, industry, or management practice.                                   |
| **Апробация результатов**                | External validation      | Demonstrates presentation, discussion, or implementation of results in scientific or professional contexts.     |
| **Публикации автора**                    | Scholarly dissemination  | Documents peer-reviewed publications derived from the research.                                                 |
| **Структура диссертации**                | Structural overview      | Explains how the dissertation is organized.                                                                     |

# Canonical Template for a Russian Dissertation Introduction

## 1. Актуальность темы исследования

**Function:** justify the importance of the research problem.

**Typical internal structure**

1. Broad macro context
2. Sector-specific or theoretical context
3. Identification of a practical or scientific problem
4. Statement that the problem requires research

**Template**

```
Современное развитие [экономики / отрасли / научного направления]
характеризуется [ключевая тенденция или проблема].

В этих условиях особое значение приобретает [область или процесс],
поскольку [обоснование значимости].

Несмотря на [существующие достижения / проводимые реформы /
развитие отрасли], сохраняется ряд нерешенных вопросов,
связанных с [формулировка проблемы].

Это определяет актуальность исследования,
направленного на [общее направление исследования].
```

---

## 2. Степень разработанности проблемы

**Function:** position the research in the literature and identify the research gap.

**Internal structure**

1. Key international research
2. Key national research
3. Summary of existing approaches
4. Identification of unresolved issues

**Template**

```
Проблемам [исследуемая тема] посвящены работы многих зарубежных
и отечественных ученых.

Значительный вклад в развитие данного направления внесли
[перечень зарубежных исследователей].

Существенные результаты в изучении указанных вопросов
получены в трудах отечественных ученых:
[перечень российских исследователей].

Однако, несмотря на наличие значительного количества
научных работ, посвященных [тема], остаются недостаточно
разработанными вопросы [формулировка научного пробела].

Это предопределило выбор цели и задач исследования.
```

---

## 3. Цель исследования

**Function:** define the intended scientific result.

**Template**

```
Целью диссертационного исследования является
[глагол: разработка / обоснование / совершенствование / формирование]
[методических подходов / моделей / механизмов / концепции]
в области [исследуемая область].
```

Typical verbs used in Russian dissertations:

* разработка
* обоснование
* совершенствование
* формирование
* развитие

---

## 4. Задачи исследования

**Function:** operationalize the research goal.

Each task should correspond roughly to a **chapter or analytical stage**.

**Template**

```
Для достижения поставленной цели в работе решаются следующие задачи:

1. Уточнить теоретические основы [исследуемого явления].
2. Проанализировать современное состояние [объекта].
3. Выявить факторы и особенности [процесса].
4. Разработать методические подходы к [решению проблемы].
5. Обосновать рекомендации по совершенствованию [механизма / системы].
```

---

## 5. Объект исследования

**Function:** define the domain of investigation.

**Template**

```
Объектом исследования являются
[процессы / системы / деятельность / предприятия],
функционирующие в условиях [контекст].
```

Example pattern:

```
процессы модернизации промышленных предприятий
```

---

## 6. Предмет исследования

**Function:** define the analytical focus.

**Template**

```
Предметом исследования являются
[экономические / организационные / управленческие отношения,
механизмы, методы], возникающие в процессе
[уточнение объекта].
```

Example structure:

```
экономические и организационные отношения,
формирующиеся в процессе модернизации предприятий
```

---

## 7. Теоретическая и методологическая основа исследования

**Function:** specify theoretical and methodological framework.

**Template**

```
Теоретическую основу исследования составляют
труды отечественных и зарубежных ученых,
посвященные проблемам [область].

Методологическую основу исследования составляют
[системный подход, институциональный подход и др.]

В ходе исследования использованы следующие методы:
[перечень методов].
```

Common methods listed in dissertations:

* системный подход
* сравнительный анализ
* экономико-статистический анализ
* метод экспертных оценок
* экономико-математическое моделирование

---

## 8. Информационно-эмпирическая база исследования

**Function:** define data sources.

**Template**

```
Информационно-эмпирическую базу исследования составили:

- нормативно-правовые акты Российской Федерации;
- статистические данные Федеральной службы государственной статистики;
- материалы научных публикаций;
- отчетные данные предприятий;
- материалы научно-практических конференций.
```

---

## 9. Научная новизна исследования

**Function:** present original scientific contributions.

Each bullet must describe **one specific new result**.

**Template**

```
Научная новизна диссертационного исследования заключается
в разработке [подхода / модели / методики].

Основные результаты, обладающие научной новизной:

• предложено ...
• разработана ...
• обоснована ...
• выявлены ...
• сформулированы ...
```

---

## 10. Теоретическая и практическая значимость

**Function:** explain scientific and applied value.

**Template**

```
Теоретическая значимость исследования заключается
в развитии положений теории [область].

Практическая значимость работы состоит в возможности
использования полученных результатов:

- при разработке ...
- при принятии управленческих решений ...
- при формировании стратегий развития ...
```

---

## 11. Апробация результатов исследования

**Function:** demonstrate validation and dissemination.

**Template**

```
Основные результаты исследования апробированы
на следующих научно-практических конференциях:

[перечень конференций].

Отдельные положения работы внедрены в деятельность
[организация].

По теме диссертации опубликовано [N] научных работ.
```

---

## 12. Структура диссертации

**Function:** explain organization of the work.

**Template**

```
Диссертационная работа состоит из введения,
трех глав, заключения, списка литературы
и приложений.

Работа изложена на [N] страницах,
содержит [N] таблиц и [N] рисунков.
```

## Common Structural Errors in Introductions

Supervisors usually check for these problems.

### 1. Missing research gap

A common weak structure:

```
importance of problem
↓
literature review
↓
goal
```

without clearly stating:

```
what exactly is unknown
```

---

### 2. Goal that does not follow from the gap

Bad example:

Gap:

> insufficient research on modernization mechanisms

Goal:

> analyze industry development

The goal must directly address the **gap**.

---

### 3. Tasks that do not lead to the goal

Each task should logically contribute to the goal.

Typical structure:

| Task                      | Purpose                     |
| ------------------------- | --------------------------- |
| Theoretical clarification | conceptual foundation       |
| Industry analysis         | empirical context           |
| Method development        | methodological contribution |
| Case study                | application                 |
| Recommendations           | practical output            |

---

### 4. Object and subject confusion

Correct relation:

```
Object = system or phenomenon
Subject = relationships within that system
```

Example:

```
Object:
modernization processes in oil refining enterprises

Subject:
economic and organizational relations arising during modernization
```

## Compressed “Supervisor Evaluation Model”

When evaluating a dissertation introduction, experts usually check only five things.

| Question                            | Section                 |
| ----------------------------------- | ----------------------- |
| Why is the topic important?         | Актуальность            |
| What is already known?              | Степень разработанности |
| What remains unknown?               | Research gap            |
| What will the dissertation achieve? | Цель                    |
| What exactly is new?                | Научная новизна         |

If these five questions are answered clearly, the introduction is usually considered **methodologically sound**.

---

## Ultra-Compact Model (The 5-Sentence Rule)

Some supervisors use a simple test:

An introduction should be reducible to **five statements**:

```
1. The problem is important because ...
2. Existing research shows that ...
3. However, it remains unclear ...
4. Therefore, the purpose of this research is ...
5. The study produces the following new results ...
```

If the dissertation cannot be summarized this way, the introduction probably lacks logical clarity.
